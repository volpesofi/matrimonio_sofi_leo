# Sito matrimonio Anna Sofia & Leonardo

Dominio: https://annasofiaeleonardo.it  
Hosting: GitHub Pages  
File principale: `index.html`

## Cosa contiene

- Hero con countdown al 6 dicembre 2026 e CTA RSVP.
- Programma della giornata con ritrovo, rito, spostamento e ricevimento.
- Mappe per rito, ricevimento e parcheggi consigliati a Marsciano.
- Informazioni pratiche su parcheggi, spostamento Marsciano → Santa Maria degli Angeli e passaggi.
- Modulo RSVP integrato e link diretto al Google Form.
- Sezione ospitalità con Marsciano come prima opzione, più alternative in autonomia.
- Lista nozze con riferimenti nascosti in un blocco apribile.

## Deploy

Ogni modifica pushata sul branch usato da GitHub Pages viene pubblicata online.

## Checklist prima di condividere il link

- Verificare link Google Maps.
- Verificare funzionamento Google Form RSVP.
- Verificare orario effettivo del rito e parcheggi consigliati.
- Aggiungere strutture consigliate quando confermate.
- Testare il sito da mobile.
- Valutare se lasciare l'IBAN visibile nel codice HTML pubblico.
